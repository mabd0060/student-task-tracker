# Student Task Tracker

A simple browser-based task tracker built to practice HTML, CSS, JavaScript, Git, and GitHub.

## Features
- Add a new task
- Mark a task as complete
- Delete a task
- Tasks are saved in localStorage — they survive page refresh

## How to run
1. Clone or download this repo
2. Open `index.html` in your browser directly, **or** serve it locally:
   ```
   python3 -m http.server 3000
   ```
   Then open [http://localhost:3000](http://localhost:3000)
3. No installation required

## What I learned
- Structuring a project with HTML, CSS, and JavaScript
- Manipulating the DOM with JavaScript
- Saving data with localStorage
- Using Git and GitHub to track and publish work
